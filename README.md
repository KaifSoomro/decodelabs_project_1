# 💼 Careely

A modern and responsive Job Portal website built using HTML, CSS, and JavaScript for DecodeLabs. The platform helps job seekers discover opportunities and enables companies to showcase available positions through a clean and user-friendly interface.

---

## 🚀 Overview

DecodeLabs Project 1 | Careely is a front-end web application designed to provide a seamless job browsing experience. The project focuses on modern UI/UX principles, responsiveness, and interactive user experiences using pure HTML, CSS, and JavaScript.
